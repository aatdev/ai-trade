## Как продолжить (команды)

Окружение: ключ FMP не нужен (данные из TradingView). Нужен **запущенный TradingView Desktop с CDP :9222**.

```bash
cd /Users/alex/Projects/Repos/tradingview-mcp-jackson

# Перескан вотчлиста (12 имён, ~2 мин) — отслеживать дозревание баз
python3 .claude/skills/vcp-screener/scripts/screen_vcp_tv.py \
  --universe BNY SATS JBL MRK CAT FDX KLAC MCHP PWR CMI VRT CNC \
  --output-dir results/vcp

# Strict-режим (только Pre-breakout/Breakout с valid VCP)

  --universe <тикеры> --output-dir results/vcp

# Полный S&P 500 заново (4 пакета, ~40+ мин; список в tmp/sp500.csv)
#   делить на чанки ≤150, гонять последовательно (один график TradingView!)

# Свод нескольких отчётов в общий шорт-лист
python3 .claude/skills/vcp-screener/scripts/aggregate_shortlist.py \
  results/vcp/vcp_screener_2026-05-29_174258.json \
  results/vcp/vcp_screener_2026-05-29_184645.json \
  results/vcp/vcp_screener_2026-05-29_192541.json \
  results/vcp/vcp_screener_2026-05-29_201833.json

  | node .claude/skills/signals-alerts/scripts/create_alerts.mjs
```
