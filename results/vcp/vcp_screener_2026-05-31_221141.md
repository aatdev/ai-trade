## Methodology

This screener implements Mark Minervini's Volatility Contraction Pattern (VCP):

1. **Trend Template** (25%) - 7-point Stage 2 uptrend filter
2. **Contraction Quality** (25%) - VCP pattern with successive tighter corrections
3. **Volume Pattern** (20%) - Volume dry-up near pivot point
4. **Pivot Proximity** (15%) - Distance from breakout level
5. **Relative Strength** (15%) - Minervini-weighted RS vs S&P 500

For detailed methodology, see the VCP methodology reference in the vcp-screener skill directory.
