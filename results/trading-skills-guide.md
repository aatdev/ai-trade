# Гайд по торговым скилам

Краткий практический справочник по установленным скилам — сгруппирован по этапам торгового процесса: от оценки рынка до постановки алертов.

---

## 🌍 1. Оценка рыночной среды (с этого начинают каждый день)

Прежде чем что-то покупать — понять, «погода» на рынке за/против тебя.

| Скил | Что делает | Когда звать |
|------|-----------|-------------|
| **uptrend-analyzer** | Считает композитный балл 0–100 по breadth рынка (5 компонентов: широта, участие секторов, ротация, моментум, история). Без API-ключа. | «Какая сейчас рыночная среда?», стоит ли вообще набирать позиции |
| **sector-analyst** | Анализ секторной ротации, cyclical vs defensive, фаза рыночного цикла | Понять, в каких секторах сейчас деньги |
| **market-news-analyst** | Собирает рыночные новости за 10 дней (FOMC/ECB/BOJ, геополитика, отчёты мегакэпов), ранжирует по влиянию | Утренний обзор макро-фона |

**Свинг-трейдеру:** запускай связку `uptrend-analyzer` → `sector-analyst` раз в неделю. Если общий балл низкий — сократи размер позиций или сиди в кэше.

## 🔍 2. Скрининг — поиск кандидатов

| Скил | Методология | Для чего |
|------|-------------|----------|
| **vcp-screener** | Mark Minervini VCP (сжатие волатильности, Stage 2) | Свинг/позиционные пробои тайтовых баз. Гонит данные на свечах из живого TradingView (обход платного FMP) |
| **canslim-screener** | William O'Neil CANSLIM (рост прибыли + моментум) | Растущие лидеры рынка |
| **finviz-screener** | Строит URL FinViz из запроса на естественном языке | Быстрый универсальный фильтр по фундаменталу/технике |
| **multi-symbol-scan** | Сканирует много тикеров на сетапы/паттерны через `batch_run` | Прогнать watchlist на один паттерн |
| **downtrend-duration-analyzer** | Гистограммы длительности коррекций по секторам/капитализации | Оценить, сколько ещё может длиться откат |

**Воркфлоу свинг-трейдера:** `vcp-screener` или `canslim-screener` → получить шорт-лист → каждый кандидат прогнать через `ticker-analysis`.

## 📊 3. Глубокий разбор одного тикера

| Скил | Что делает |
|------|-----------|
| **ticker-analysis** ⭐ | **Главный координатор.** Полный разбор тикера: новости + фундаментал + техника + график. Вызывает внутри `market-news-analyst`, `us-stock-analysis`, `technical-analyst`, `chart-analysis`. Сохраняет 4 markdown + скриншоты daily/weekly в `results/analysis/TICKER/DATE/`. Даёт **конкретные точки входа/выхода**. Алерты **не** ставит, пока явно не попросишь |
| **us-stock-analysis** | Фундаментал: метрики, качество бизнеса, оценка стоимости + сравнение тикеров |
| **technical-analyst** | Чистая техника по графику: тренд, S/R, сценарии, вероятности (без новостей/фундаментала) |
| **chart-analysis** | Настраивает график: символ/ТФ, индикаторы, аннотации, скриншот |

**Это рабочая лошадка.** Для решения «покупать ли X» — просто `«проанализируй AAPL»` → `ticker-analysis` сделает всё и выдаст уровни входа, стопа и целей.

## 🔔 4. Алерты и исполнение

| Скил | Что делает |
|------|-----------|
| **signals-alerts** | Синхронизирует алерты TradingView с журналом `results/analysis/signals.md`. По каждому сигналу — 5 алертов: Trigger / Stop / T1 / T2 / T3 |
| **collect-data** | Снимает OHLCV + котировку + индикаторы в JSON для офлайн-анализа |

> ⚠️ Из памяти проекта: штатный `alert_create` подломан (хэшированные CSS-классы) — `signals-alerts` обходит это через `ui_click` + `ui_evaluate`.

**Воркфлоу:** после `ticker-analysis` записал сигнал в `signals.md` → `«синхронизируй алерты»` → `signals-alerts` ставит триггеры в TradingView.

---

## 🛠 5. Стратегии и практика (Pine + Replay)

| Скил | Что делает |
|------|-----------|
| **pine-develop** | Цикл разработки Pine Script: код → компиляция → фикс ошибок |
| **strategy-report** | Отчёт по бэктесту: метрики, анализ сделок, equity curve, рекомендации |
| **replay-practice** | Тренировка в Replay-режиме: шагаешь по барам, берёшь сделки, считаешь P&L |
| **tradingview-mcp** | Базовый доступ к живому графику (котировки, индикаторы, OHLCV) — основа для остальных |

**Свинг-трейдеру:** проверяй сетап на истории через `replay-practice`, прежде чем доверять ему реальные деньги.

## 🎯 Типовые сценарии

**Утренняя рутина (10 мин):**
```
uptrend-analyzer → market-news-analyst → sector-analyst
```
Решаешь: торговать сегодня или нет, какие сектора в фокусе.

**Свинг-сетап от и до:**
```
vcp-screener / canslim-screener   (найти кандидатов)
       ↓
ticker-analysis по каждому        (полный разбор + уровни)
       ↓
replay-practice                   (проверить сетап на истории)
       ↓
signals-alerts                    (поставить триггеры в TradingView)
       ↓
send-telegram                     (отправить себе план)
```

**Быстрая проверка идеи:**
```
«проанализируй TSLA» → ticker-analysis → готовый отчёт с точками входа
```
